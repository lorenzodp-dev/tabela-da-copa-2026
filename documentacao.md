# **Documentação Ténica**
## **Requisitos Técnicos**:
### **Aplicação desktop**:
Linguagem: C# (Visual Studio 2022)

BD: PostgreSQL

Infraestrutura de hospedagem: Windows 10 ou superior

### **Aplicação web**:
Linguagem:
- **FRONT**: HTML, CSS, JS, React
- **BACK**: Node.js, JS, PHP (possivelmente) 

BD: MySQL ou MariaDB

Infraestrutura de hospedagem: 
- hospedagem web (1vCPU, 2GB RAM, 50GB armazenamento)
- domínio (ver registro.br)
- serviço de segurança (CloudFlare ou similar)
### **Aplicação mobile**:
Linguagem: React Native (JS)

BD: sem uso (API)

Infraestrutura de hospedagem: Expo (ambiente que simula as lojas desenvolver Android e iPhone)
