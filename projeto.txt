ANÁLISE DE REQUISITOS:

RF-01: Gestão de grupos

	O sistema deve permitir o cadastro de grupos de A a L.

RF-02: Gestão de seleções

	O sistema deve permitir o cadastro das 48 seleções, incluindo:
		
		Nome
		Bandeira
		Abreviação
		Grupo

	Regra: o grupo deve ser selecionado do cadastro de grupos existente

RF-03: Gestão de Sedes

	O sistema deve permitir cadastro das sedes, incluindo:

		Nome do país
		Cidade
		Estádio
		Capacidade do Estádio

RF-04: Gestão de Partidas

	O sistema deve permitir cadastro das partidas, incluindo:

		Data
		Horário
		Sede
		Seleção mandante
		Seleção visitante

	Regras: A sede deve ser selecionada; as seleções mandantes e visitantes devem ser selecionadas;

RF-05: Tabela das partidas

	O sistema deve permitir a criação da tabela com as partidas para visualização pelo usuário

	Regras: as partidas precisam ser organizadas em grupo e em data cronológica (ordem de classificação é extremamente necessária)

RF-06: Resultados das Partidas

	O sistema deve permitir a inclusão dos resultados das partidas com a opção de incluir a quantidade de gols que cada seleção marcou

	Regras: os resultados devem ser igual ou maior que 0.

RF-07: Classificação

	O sistema deve permitir a visualização do ranking de cada grupo, mostrando os melhores classificados em primeiro.
	
	Regras: os critérios para a geração do ranking deve ser:

		1. Pontuação
		2. Quantidade de vitórias 
		3. Saldo de gols
		4. Verificar os demais critérios...

RF-08: Avanço de Fases

	O sistema deve calcular quais seleções irão avançar para a próxima fase

	Regras: 

		Os 2 primeiros colocados de cada grupo avançam para a próxima fase, totalizando 24;
		Os 8 melhores colocados dentre os restantes também avançam para a próxima fase, totalizando, assim, 32 seleções.
		Demais regras verificar-se-á.
